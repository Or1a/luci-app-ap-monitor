## 字段限制

- HTTP 关联列表的 `signal` 出现 72、138 等正数，转换规则没有核实，因此不显示为百分比或 dBm。
- 路由器 `channelInfo.bandwidth` 和配置字段会同时返回 `0`。当前不把该值推断为实时信道宽度。
- 型号和固件来自路由器 `misystem/status.hardware`，无需额外请求 `init_info`。仅返回型号及版本，排除序列号、账号标识等字段。
- OpenWrt 只有明确的关联状态才计入终端；缺失关联标志会标记查询失败，避免错误显示零台。
- 查询的是某个时点的接口数据。没有通过漫游实测验证终端切换过程，也没有测量转发、丢包或互联网可用性。

后续实机验证需要设备型号、固件版本、可用的 SSH 登录方式和已核对的主机身份。验证时只读取接口与系统数据。
